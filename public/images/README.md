# Al Shukr Dairy Farm — Image Assets

Place real farm photography here. Components read from `src/lib/images.ts`.

## Folders

| Folder | Purpose |
| --- | --- |
| `brand/` | Official logo (already populated) |
| `farm/` | Hero pasture, editorial farm, final CTA field |
| `process/` | Healthy animals, collection, quality, delivery |
| `animals/` | Emotional animal-care photography |
| `milk/` | Pouring / bottle / container detail shots |

## Replacement

1. Add your JPG/WebP files using the `localHint` filenames in `src/lib/images.ts`.
2. Change each image's `src` to the local path (e.g. `/images/farm/hero-pasture.jpg`).
3. Keep alt text accurate to the real photograph.

Temporary Unsplash URLs are production-quality stand-ins only — swap them for authentic Al Shukr farm imagery before launch.
